# 起動アニメーション・アイコン

2026-10-26にユーザー制作の素材をiOS版へ組み込み。

- アイコン元：Downloads/アプリアイコン.ai（PDF互換のIllustratorファイル）。アートボードを1024×1024の不透明PNGへ変換。通常のAppIconカタログと、実機向け簡易ビルド用の120/180px PNGを更新。
- 起動動画元：Downloads/positivefinger/PositiveFinger_iOS_1.mp4（1080×1920、60fps、音声入り）。動きは冒頭約1.02秒、音は約1.17秒まで。その後の静止区間を除き、冒頭約1.8秒を再圧縮せず同梱。元ファイルは変更しない。
- 同フォルダの起動音MP3は重ねて再生しない。動画に含まれる音を利用する。
- iOSの静的Launch Screenは動画の先頭画像。アプリ起動後にAVPlayerLayerで一度だけ再生する。ログイン状態・通信完了を待たない。
- resizeAspectFillで縦横比を維持し画面全体を覆う。セーフエリアを含めて表示し、画面比率の差は中央を基準に端を切り取る。動画自体の白背景は演出の一部。
- コントロール・黒帯を出さず、再生後はログイン画面またはホームへ進む。バックグラウンド復帰では最初から再生しない。
- 再生失敗・素材欠落時も先へ進む。停止した動画の待機上限は4秒。iOSの「視差効果を減らす」が有効な場合は静止ロゴを短く表示して進む。

ビルド確認：iPhoneOS向け、既存のシミュレータ不要のビルド経路を使用。実機上の映像・音声確認は別途必要。
