# PositiveFinger / ポジティブフィンガー

「いつもの文字入力から、ちょっと前向きな毎日へ。」

2026年10月22日の[仕様書v0.1](docs/SPEC.md)に合わせたiPhone用プロトタイプです。azooKeyの日本語キーボードを利用して、確定した入力から前向きな表現の候補を端末内で検出します。

## 実装した機能

- 日本語フリック入力・かな漢字変換・削除・キーボード切り替えの実装をazooKeyから利用。
- 入力確定や直接入力時に登録語句を照合。候補選択・確定を契機とし、送信ボタンの押下や送信成功を判定するものではありません。
- キーボードの固定高さのヘッダーに約2秒だけ「前向きな表現の候補を見つけました」を表示。候補欄やキーを覆わず、タッチ操作を受け取りません。「視差効果を減らす」に対応。
- メインアプリに累計検出回数、今日の回数、直近7日の日別グラフを表示。日別集計は直近30日分のみ保持。
- 表示のオン・オフと、最短表示間隔（30秒・1分・3分）をApp Groupで共有。表示オフでも集計します。プッシュ通知は使用しません。
- 同じ正規化テキストの再確定は30秒間、重複集計を防止。アプリ・拡張の共有ファイルを排他ロックして更新。
- 機密入力の属性を確定時に確認し、secureTextEntry・password・newPassword・oneTimeCode・creditCardNumberを検出対象から除外。属性を取得するコントローラが不在の場合も解析しません。
- ポイント付与は保留。旧プロトタイプの累計ポイントはデータ移行時に保持しますが、新規付与・画面表示は行いません。旧加算回数を累計検出回数として引き継ぎ、根拠のない過去の日別履歴は生成しません。
- SNS API連携は未実装。

## プライバシーと限界

入力文・入力履歴・検出語句は保存せず、外部にも送信しません。保存するのは集計、設定、旧ポイント数値、直近の表示日時、重複防止のためのソルトと短期間のハッシュです。期限切れのハッシュは次回読み書きで除去します。変換学習、コピー履歴保存、変換報告・単語共有送信、入力内容のデバッグログを無効化しています。

検出は語句の一致に基づきます。否定や引用の文脈を理解するものではなく、心理状態や心理的効果の評価ではありません。おためしボタンによる判定は集計しません。

独自キーボードを使えないアプリや機密入力欄ではiOS標準キーボードへ切り替わります。フルアクセス未許可時も入力と既定設定によるフィードバックは動作しますが、共有集計とメインアプリで変更した設定の反映にはフルアクセスが必要です。

## Xcode・実機での起動

1. `PositiveFinger.xcodeproj` を開き、PositiveFingerスキームを選択。
2. アプリ本体とPositiveFingerKeyboardのSigning & Capabilitiesで開発Teamを設定。
3. 両ターゲットにApp Group `group.com.positivefinger.PositiveFinger` を登録。IDを変更するときは、両entitlements、PositiveActivityStore、Vendor内SharedStoreも同じIDへ変更。
4. iPhoneで起動。設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加 → Positive Finger。
5. 集計・設定共有のため「フルアクセスを許可」をオン。
6. 地球儀キーで切り替え、「ありがとう」を入力・確定。ヘッダーに表示され、ホームへ戻ると検出回数が増えます。同じ入力は30秒以内に増えません。
7. 表示オフ、表示間隔、日別集計、パスワード欄で標準キーボードに戻ることを実機確認してください。

署名・インストールにはApple側でApp Groupsを利用できるアカウント設定が必要です。共有保存ができない場合、別の保存先へ集計を記録して成功扱いにはしません。

`swift test` で語句一致、重複防止、旧データ移行、集計保持期間、同時更新、機密入力の除外、フィードバック設定・頻度、共有保存先がない場合を検証します。

2026年10月22日：自動テスト8件が成功し、画像カタログを除いたDebugコードビルドでアプリ本体とキーボード拡張のコンパイルに成功しました。

その後、追加ランタイムなしで、iPhone 8（iOS 16.7.8）向けの署名付きビルド・インストール・実機起動に成功しました。Personal Teamで端末登録とApp Groupsを含む両ターゲットのプロファイル生成を確認しています。

再現用のコマンドは `bash scripts/build-iphone.sh`。詳しくは[実機ビルドと転送の手順](docs/DEVICE_RUN.md)を参照してください。

この経路ではXcode 15.3の内部診断設定 `-IDEPlatformCoordinatorIgnoreSimulatorStatus=YES` をコマンドごとに指定し、`EXCLUDED_SOURCE_FILE_NAMES=*.xcassets` で画像カタログ処理を省いています。キーボードの配色には同じ色定義を使うフォールバックを追加しました。画像カタログを含む通常ビルドと、キーボード入力・フィードバック・日別集計の実機操作テストは別途必要です。
