# Positive Finger / ポジティブフィンガー

前のチャット「ポジティブフィンガー案」の仕様に基づくiOSアプリです。azooKeyの日本語フリック入力・かな漢字変換を使い、確定した言葉に応じてポイントを貯めます。

## 実装した機能

- ホーム画面：累計ポイント、今日のポイント、加算回数、キーボード導入案内、おためし判定。
- azooKeyの候補選択・確定処理にポジティブ判定を接続。おためし画面はポイントを付与しません。
- 登録語句方式。長い語句を優先し、「大好き」と「好き」の二重加算を防ぎます。感情や文脈を理解するAI判定ではありません。
- App Group `group.com.positivefinger.PositiveFinger` を両ターゲットで使用。
- 共有ファイルを排他ロックし、原子的に更新。同じ正規化テキストは30秒間加算しません。再起動や他の文章を挟んでも重複防止が働きます。
- 保存するのは数値、日付、ランダムなソルト、短期間の重複判定用ハッシュのみ。入力文、検出語句、入力履歴は保存しません。
- 変換学習、コピー履歴保存、単語共有送信、入力内容のデバッグ出力を無効化。

## Xcodeと実機での起動

1. `PositiveFinger.xcodeproj` を開き、PositiveFingerスキームを選択。
2. アプリ本体とPositiveFingerKeyboardの両方のSigning & Capabilitiesで、ご自身の開発Teamを設定。
3. App Groupsに `group.com.positivefinger.PositiveFinger` を登録。IDを変更する場合は、両entitlements、PositivePointManager、Vendor内SharedStoreも同じIDに変更。
4. iPhoneを選んで実行。端末の設定 → 一般 → キーボード → キーボード → 新しいキーボードを追加 → Positive Finger。
5. ポイント共有のため「フルアクセスを許可」をオン。フルアクセス未許可でもキーボード入力は使用できますが、共有保存はできません。ネットワークへの送信処理はありません。
6. 地球儀キーで切り替え、「ありがとう」を入力・確定。ホーム画面に戻ると10ptを確認できます。同じ言葉を30秒以内に確定しても増えません。

署名・実機インストールにはApple側のApp Groups対応アカウント設定が必要です。共有コンテナが利用できない場合、別の保存先にポイントを書いて成功扱いにはしません。

## 確認

`swift test` で判定・再起動後の重複防止・日付切替・同時書き込み・入力文非保存を検証します。

2026-10-21の確認結果：自動テスト5件成功。実機向けSDKによるアプリ本体・キーボード拡張のDebug/Releaseコードビルドに成功しました。

このMacではiOS 17.4シミュレータのランタイムが未導入のため、通常ビルドは画像カタログのコンパイルで停止します。コード検証時はコマンドライン限定で `EXCLUDED_SOURCE_FILE_NAMES=*.xcassets` と `CODE_SIGNING_ALLOWED=NO` を指定しました。プロジェクト本体の画像カタログは残しています。完全な通常ビルド、画面の目視検証、キーボードの実機操作は未確認です。

通常ビルドには、XcodeのSettings → Platformsで対応するiOSランタイムを導入し、署名を設定してください。
