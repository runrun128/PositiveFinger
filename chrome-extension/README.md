# PositiveFinger Chrome版（プロトタイプ）

## 入れ方
1. Chromeで `chrome://extensions` を開く。
2. 右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」で、この `chrome-extension` フォルダーを選ぶ。
4. 拡張機能を開き、iPhoneと同じメールアドレスでログインする。
5. 使うWebページを開き、拡張機能の「オンにする」を押す。ページ単位で使う場合は、移動後にもう一度オンにする。
6. YouTubeなど毎回使うサイトでは「このサイトで常に使う」を押し、Chromeの確認で許可する。ドメイン単位で許可を保存し、次に開いたページでも自動で有効になります。解除は「サイトの許可を解除」から。

タイプ音は拡張内で切り替えられます。入力確定またはEnterで言葉を検出します。Chromeの設定画面・ストア・一部の特殊なエディターや埋め込み入力欄では使えません。既存の日本語入力をそのまま使います。

## ポイントと遊び
同じアカウントならiPhoneとクラウド残高・相棒・交換アイテムを共有します。ガチャ（25pt）、称号・背景の交換、チェックイン、ミッション、共同イベントに対応しています。CPU練習バトルはiPhone版にあります。オンライン対戦とギフト券交換は未実装です。

## 入力データ
判定はページ内で行い、入力文は保存・送信しません。クラウドへ送るのは検出イベントの識別子です。パスワード、認証コード、支払い情報と判断できる入力欄は除外します。ページ側の入力欄の設定によっては機密情報の種類を完全には判別できないため、機密情報を扱うページではオンにしないでください。認証情報はページのスクリプトからアクセスできない拡張の保存領域に置きます。

Chromeウェブストア未公開です。実際のChromeへの読み込み、ログイン、iPhoneとの同期の実機確認はまだ行っていません。開発用テストは `node --test chrome-extension/tests/*.test.cjs` で実行できます。

## 更新後に権限エラーが出る場合
「Only permissions specified in the manifest may be requested.」と出たら、Chromeが以前の権限設定を保持している可能性があります。
1. `chrome://extensions` でPositiveFingerのカードにある再読み込み（↻）を押す。ポップアップ上部の更新ボタンとは別です。
2. YouTubeなどのページも再読み込みし、拡張を開き直す。
3. 「このサイトで常に使う」を押す。
解消しない場合は「詳細」のバージョンが0.2.0か確認し、更新済みのフォルダーを読み込んでください。
